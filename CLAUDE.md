# Claude project instructions

Read `AGENTS.md` before doing any work. It describes the concept, the current stage, how the prototype works, how to check changes, and the privacy rules.

## Claude is not an author of this portfolio

This is Shawn Garello's portfolio, and Shawn is its author. Claude helps on the project as an assistant. Claude is not an author, contributor or co-creator of the portfolio, and it must not be presented as one anywhere in this repository.

- Every commit uses Shawn's configured Git identity. Claude must never be the commit author or committer.
- Never add `Co-authored-by: Claude`, an Anthropic identity, or any other AI co-author trailer.
- Never add "Generated with Claude Code" or any similar attribution to commit messages, pull request descriptions, code comments, documentation, the README, credits, a colophon or site content.
- Do not override Git identity settings or set author or committer environment variables. If no valid human identity is configured, stop and ask Shawn.
- Before reporting a commit as done, check its author, committer and full message.

## Working rules

- Stay within the current stage in `AGENTS.md`. The framework, final art, license and content are Shawn's decisions; propose them, don't start them.
- Don't push, open pull requests or change repository settings unless Shawn asks.
- Make commits small and honest: one meaningful step per commit, with a message that matches the change.
